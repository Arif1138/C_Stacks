# Stack Implementation in C

This repository contains a basic Stack data structure implementation written in C. 
It demonstrates the LIFO (Last-In-First-Out) principle using standard operations.

## Features
- **Push:** Add an element to the top of the stack.
- **Pop:** Remove and return the top element.
- **Peek / Top:** View the top element without removing it.
- **isEmpty / isFull:** Check the current state of the stack.

## How to Run
1. Compile the source code using a C compiler (e.g., GCC):
   gcc stacks.c -o stacks
2. Run the compiled executable:
   ./stacks.c
